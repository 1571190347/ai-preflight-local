# YouTube 首期：把 AI 环境检测工具装在自己电脑上

目标时长约 4 分钟。形式为本人旁白加真实本地录屏；下面的时间是剪辑建议，不是已经录制或精确测量过的配音时长。源码与安装说明：https://github.com/1571190347/ai-preflight-local。

建议标题：**《不想把环境信息交给陌生网站？本地搭建 AI 体检站》**

封面文字：**检测工具，自己运行**

## 0:00–0:25 · 为什么做这个工具

画面：浏览器地址栏显示 `127.0.0.1:4173`，切到工具总览；先打开 IP 遮罩。

旁白：

> 用 Claude 或 ChatGPT 时，遇到连接失败，很多人会先找一个 IP 检测网站。但这些网站会收到哪些信息？结果里的风险分又代表什么？我做了一个可以在自己电脑上运行的检测工具，源码、自动检测目的地和结果依据都可以自己看。今天带你从启动到看懂结果，完整走一遍。

## 0:25–0:55 · 一行安装与启动

画面：展示 GitHub README 与开源安装脚本；终端粘贴对应系统的安装命令，打开本地页面。录屏前先核对该版本的验证记录。

屏幕命令：

```sh
curl -fsSL https://raw.githubusercontent.com/1571190347/ai-preflight-local/main/install.sh | sh
```

旁白：

> 打开 GitHub 上的安装说明，复制对应系统的一行命令。安装器会校验发行包；没有合适的 Node 时，会下载项目自己使用的运行时。安装完成后服务在本机后台启动，并打开页面，不需要安装开发依赖，也不需要工具账号。README 里有启动、停止和卸载方法，需要改源码的人可以按开发说明操作。

Windows 录屏使用 README 中的 PowerShell 命令：`irm https://raw.githubusercontent.com/1571190347/ai-preflight-local/main/install.ps1 | iex`。

## 0:55–1:25 · 先检查本地浏览器

画面：页面打开后自动出现报告；展开两条风险或未知项，并展示 Network 面板中的自动报告目的地。

旁白：

> 现在打开页面会直接生成一份体检报告：当前出口、IP 属性、公开风险标签，以及 Claude 和 ChatGPT 的入口连接情况。每一项都会标明数据来源；没有取得风险字段时会写“资料不完整”，不会假装 IP 一定干净。报告之外的 Canvas、WebRTC、DNS 和 Ping 等深度检测仍由你手动运行。

## 1:25–2:00 · 检查出口与连接

画面：IP 与分流，展示目的地说明，主动允许并运行；切到 Claude/ChatGPT 页面和连接结果。保持 IP 遮罩，保留真实未知结果。

旁白：

> 外网检查就需要观察点了。运行前先看它会请求哪些服务。不同目标返回的出口，可以放在一起比较。但请注意，浏览器和本地后端可能走不同的代理路径，后端看到的 IP 不能直接当成 Claude 看到的全部环境。还有，网页请求因为跨站规则读不到结果时，工具会写明无法确认，不会直接说你的账号被封了。

## 2:00–2:35 · IP 画像与分数

画面：输入自己正在排查的公网 IP；展示多源结果的来源、时间和空字段；切到未配置密钥提示。不要录真实 `.env`。

旁白：

> IP 画像可以查地区、ASN、运营商，以及不同数据源提供的标签。基础查询不一定需要密钥，但完整的代理、VPN 等标记可能需要你自己配置服务密钥。字段缺失，就保持未知。举报置信分也有明确来源，它是数据服务的分数，不是 OpenAI 或 Claude 的内部评分，更不是封号概率。两个数据源说法不同的时候，先看定义和证据，不把它们硬拼成一个总分。

## 2:35–3:15 · DNS、WebRTC 与 Ping

画面：依次打开 DNS、WebRTC 和 Ping 的说明；展示 DNS 未配置提示与 `services` 目录。Globalping 的公共测量提示保持可见，不必为拍摄额外提交敏感目标。

旁白：

> DNS 有本机信息和自建权威观测两部分。后者需要你自己的域名和公网服务器，部署说明也在包里；不配置它，其他功能照样能用。WebRTC 会使用你选择的 STUN，拿可见候选和 HTTP 出口做对照。全球 Ping 可以用 Globalping，但目标和测量可能公开；更在意控制权，可以用配套代码搭自己的节点。远程节点的延迟，也不等于你浏览器的连接速度。

## 3:15–3:45 · 把脱敏报告交给 AI

画面：回到总览点击“复制给 AI”，在文本编辑器展示 Markdown 的结论、事实、发现和分析边界；确认公网 IP 已被替换成“已隐藏”。

旁白：

> 检测完成后，可以把 Markdown 报告交给你常用的 AI。它会自动隐藏公网 IP，保留地区、ASN、数据覆盖、每条证据和建议，还附了一段分析要求：未知项不能当通过，也不能凭空猜平台内部评分。AI 可以帮你把问题按优先级整理，但最终还是要对照官方支持地区和工具里的原始来源。组织和地区仍可能有隐私信息，发送前自己再看一遍。

## 3:45–4:05 · 交付与边界

画面：README、隐私说明和功能覆盖表；最后停留在本地地址与工具总览。

旁白：

> 我分享的是一套可以阅读和修改的本地工具，帮助你知道检查了什么、数据发给谁、哪些地方还不能确认。它不能保证账号不受限制。下载方式和文档会放在简介，你也可以自己检查源码，按自己的需求保留数据源。遇到问题时，请提供脱敏的复现步骤，一起把工具做得更准确。

## 简介草稿

这期演示在自己的计算机上运行 AI 体检站：公网 IP、浏览器环境、网络连接、DNS、WebRTC、Ping、服务状态、WHOIS/RDAP 与静态 IP 卡片。

源码与一行安装：https://github.com/1571190347/ai-preflight-local

完整发行包：https://github.com/1571190347/ai-preflight-local/releases/latest

一行安装器可按需安装私有 Node.js；手动启动需要 Node.js 22.13+。首页会自动请求公开出口、IP 数据源和 AI 入口来生成报告；其他深度检测按需运行。Globalping 测量可能公开；自建 DNS 是额外的可选组件。本工具不预测账号封禁，不提供 Claude/OpenAI 私有信任分。
