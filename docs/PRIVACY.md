# 数据与隐私

本说明适用于原始本地版本。代码在自己的计算机运行；维护者不提供结果收集服务器，不接收检测报告，不接收浏览器指纹。第三方数据源仍会接收到用户主动触发的网络请求。修改后的分支、代理、浏览器扩展和自建服务器可能改变此行为。

## 默认状态

- 打开页面只加载本机资源和本机配置，不启动外部检测、STUN、RSS、统计或遥测。
- 浏览器检查在用户点击后执行，结果默认保留在当前页面内存。
- 保存历史是可选操作；只将脱敏摘要写入当前浏览器的本地存储。
- 不要求 Claude、ChatGPT 账号密码、登录 Cookie、对话内容或平台 API 密钥。
- IP 数据服务与 DNS 收集器的可选密钥由本地 Node 服务读取，不嵌入前端构建文件。

“本地运行”表示处理逻辑和界面由你控制；测量外网仍需要与所选的外部观察点通信。网络数据提供方能看到请求的来源 IP，即使你把查询结果中的 IP 隐藏了。

## 每种检查会发送什么

| 操作 | 接收方 | 离开本机的数据 | 结果保留位置 |
| --- | --- | --- | --- |
| 浏览器能力、时区、语言、Canvas/WebGL 演示 | 无外部接收方 | 无检测结果外发 | 当前页面；仅主动选择的摘要可入历史 |
| 本机 DNS、接口信息 | 本机 Node 服务；系统配置的 DNS 解析器处理域名解析 | 被查询域名会经过系统 DNS 路径 | 本机服务响应及当前页面 |
| 浏览器公网 IP / trace | 所选 ipify、Cloudflare、Claude、ChatGPT 或自定义端点 | 浏览器出口 IP、请求时间及常规网络/HTTP 元数据 | 当前页面 |
| 本地服务公网 IP / trace | 所选端点 | Node 服务的出口 IP和常规请求元数据 | 当前页面 |
| 后台 DNS 兼容 | Cloudflare DoH（固定 1.1.1.1） | auto 模式仅在系统返回 Fake-IP 时发送被查询域名；doh 模式始终发送，system 模式关闭；从不发送数据源密钥 | 本次操作内存 |
| IP 画像 | 所选 ipapi.is、ipwho.is、AbuseIPDB、Shodan | 输入的公网 IP；配置的对应服务密钥只发送给该服务 | 当前页面 |
| HTTP 连通测试 | 被选择的网站/API | 请求资源、出口 IP、时间与常规请求元数据 | 当前页面 |
| WebRTC | 选择的 STUN 服务器 | 网络地址与 STUN 协议数据 | ICE 候选在当前页面展示 |
| 权威 DNS 观测 | 递归解析器与自己控制的权威 DNS 收集器 | 随机测试域名；权威端看到的递归解析器 IP、查询类型与时间 | 收集器短期内存、当前页面 |
| 全球 Ping | Globalping 或自己配置的节点及检测目标 | 目标域名/IP、节点数量、包数等测量参数 | 第三方测量服务及当前页面 |
| 服务状态 | 所选官方状态页 | 状态请求、出口 IP和时间 | 当前页面 |
| WHOIS/RDAP | IANA 与匹配的注册局/注册商服务 | 输入的域名/IP/ASN | 当前页面；WHOIS 使用明文 TCP 43 |
| AI 资讯 | 选中的 RSS/Atom 站点 | 订阅源请求与常规元数据 | 当前页面；点击原文会在浏览器访问原站 |
| 卡片生成和导出 | 无外部接收方 | 无 | 下载文件；由你决定是否分享 |

当浏览器与本地服务使用不同代理策略时，两者的请求会走不同路径。报告会保留观察点信息，不能把 Node 的出口当成浏览器出口。

所有外部服务还可能按自身规则保留访问日志。本工具无法清除这些服务的记录。实际目的地可以在“数据与设置”及 `server/config.mjs`、`config.local.json` 中核对；修改配置后，以你的配置为准。

## 公共测量与自建 DNS

Globalping 用于公共网络测量，目标和结果应按可公开读取的信息处理。不要把不愿公开的目标名称写入公共测量；可选择不运行，或配置自己的节点。接口能力与限额见 [Globalping API](https://globalping.io/docs/api.globalping.io)，第三方政策见 [Terms & Policies](https://globalping.io/terms)。

配套 DNS 收集器需要你控制的公网基础设施。它把随机测试域名映射到短期会话，记录向权威端查询的递归解析器 IP、查询类型和时间；会话默认 120 秒后到期，只在进程内存保存。删除会话或停止进程也会清除这些会话数据。它不记录包体、测试域名和 IP 到应用日志。反向代理、主机服务商、防火墙或递归解析器仍可能另外记日志，需要由基础设施管理者决定保留策略。

## 保存、遮罩、导出与清理

显示遮罩是避免截图中直接露出 IP 的辅助功能，原始结果仍可能存在当前页面内存。不要把屏幕遮罩当作匿名网络服务。内置报告、历史、卡片导出始终执行脱敏。脱敏不是匿名化保证；查询域名、组织、地理字段仍可能保留。手工复制原始结果、截图或修改版仍可能含敏感信息，分享前请检查内容。

清空历史只删除本工具在当前浏览器保存的历史摘要；刷新或关闭页面可释放当前结果。浏览器“清除站点数据”还可以删除该本地地址的存储。已下载的 JSON、SVG、PNG、截图、视频和备份需要自行删除。

分享代码时排除 `.env`、`config.local.json`、个人报告和包含密钥的日志。共享示例配置应使用占位值。开源本项目代码不代表可以再分发第三方数据集；例如 [ipwho.is 条款](https://ipwhois.io/terms) 对数据库复制和服务再分发有单独限制。

## 如何自己核对

1. 启动本地版本，打开浏览器开发者工具的 Network 面板，刷新并暂不点击检测。此时应只有本机资源与配置请求。
2. 分别运行一个模块，核对请求目的地与上表。浏览器面板只显示浏览器请求；Node 后端的外部请求需要结合源码或主机网络工具查看。
3. 在 Application/Storage 面板确认首次使用没有自动保存历史；主动保存后查看脱敏内容，再执行清空。
4. 在项目和构建文件中检索 `fetch`、`https.request`、`RTCPeerConnection`、`localStorage` 以及第三方域名，检查与预期是否一致。

本说明描述可核查的设计行为，不是第三方独立安全审计证明。具体运行结果和已验证范围见项目的验证记录。
