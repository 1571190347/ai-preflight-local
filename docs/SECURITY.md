# 安全模型与报告

本项目是一套给计算机所有者主动运行的本地诊断工具。默认部署范围是同一台计算机的浏览器与 Node 服务。不要把修改为公网监听、套上共享反向代理的部署视为与默认本地版本具有相同的安全边界。

## 保护范围

核心关注对象是本地配置中的数据服务密钥、当前检测结果、本机网络信息和主动测试范围。设计主要防止远程网页借用本地服务、用户输入诱导后端访问私有网络、第三方响应注入页面，以及查询密钥进入浏览器构建或公开代码。

它不防御已控制操作系统的进程、恶意浏览器扩展、用户安装的篡改构建，也不能保证第三方数据库正确、平台不限制账号或网络观察点不保留日志。

## 本地服务的防护机制

| 入口或数据 | 实现约束 | 需要理解的范围 |
| --- | --- | --- |
| 监听地址 | 默认绑定 `127.0.0.1` | 环回绑定降低网络暴露，不代表同机其他进程不可访问 |
| 浏览器到本地 API | 校验 Host、Origin 与请求来源；写入/检测请求要求 JSON | 开发代理的 origin 仅作为显式开发配置；不使用任意来源 CORS |
| 任意域名/IP 输入 | 校验域名、IP、ASN 格式；拒绝路径、端口和私有/保留目标 | 查询框不是开放代理或任意 URL 抓取器 |
| 后端 HTTPS 出站 | 限定 HTTPS 标准端口；先校验 DNS 地址，实际连接固定到校验过的地址 | 降低 DNS 重绑定和 SSRF 风险；代码变更时需保留这一步 |
| HTTP 重定向 | 每跳重新校验目标并限制跳数；带密钥请求不得把密钥转发到其他源 | 不因初始 URL 合法就信任重定向目标 |
| 响应和请求资源 | 设置超时、大小上限和模块级数量上限 | 这些限制避免一次请求无限等待或消耗资源，不是公网抗滥用服务 |
| WHOIS | 固定使用 TCP 43；校验 IANA 引用的公网主机，限制响应和等待时间 | WHOIS 不加密；优先使用 HTTPS RDAP |
| 服务密钥 | 从本机 `.env` 读取，排除版本控制 | 不应使用 `VITE_` 前缀；Vite 的公开变量会进入前端代码 |
| 外部数据展示 | 把提供方字段作为数据处理，不执行外部脚本 | 不将 RSS、WHOIS、错误字符串作为可信 HTML 插入页面 |
| IP 卡片 | 本地生成 SVG/PNG；文本需要转义 | 不包含远程追踪像素或执行脚本 |
| 测量触发 | 外部检测由用户主动启动 | 启动/切换页面不等同于同意向所有第三方发送请求 |

具体实现以 `server/security.mjs`、`server/index.mjs`、提供方适配器和前端代码为准。仅有防护代码并不能替代运行验证；每次修改这些边界后应重跑相关测试。

## 权威 DNS 收集器

DNS 收集器是独立的可选公网组件，不随本地页面自动启动。公共 DNS 监听器只回答已配置区域，不能作为开放递归解析器使用。会话主机名采用随机值；API 使用独立 Bearer 令牌，默认只绑定环回地址，由管理者配置 HTTPS 反向代理。浏览器不直接取得管理令牌。

实现包含会话有效期、会话容量、观察条数、请求体长度、DNS 消息长度、TCP 连接/帧数及速率限制。默认会话 120 秒，最多 1,000 个活动会话；数据仅保存在内存。域名 NS 委派、UDP/TCP 53、HTTPS 证书和代理访问控制需要管理者实际配置并验证。完整配置以收集器 README 为准。

不要把本地后端的认证边界与 DNS 组件的公网边界混为一谈。主应用保持环回监听；DNS 服务只有协议所需的公网入口开放，管理 API 应通过配置的 TLS 和令牌保护。

## 维护与验证

在发布源码包前核对以下与本项目直接相关的行为：

1. 未点击检测时无第三方请求，无自动保存指纹/完整报告。
2. 非本机 Host、跨站 Origin、非 JSON 检测请求被拒绝。
3. 私网、环回、保留 IP、域名解析到私网及重定向到私网均被拒绝；正常公网测试仍可运行。
4. 缺密钥、限流、超时、404、非 JSON 与不兼容字段明确显示未知或错误。
5. `.env`、密钥、个人报告、DNS 会话及运行日志未进入发布压缩包和前端构建。
6. 本地历史和导出按用户选择处理敏感字段；清空操作确实删除对应存储。
7. DNS 收集器的未授权访问、过期会话和畸形 DNS 请求被拒绝。

这些是测试范围说明，不是全部已经通过的声明。以本次发布随附的验证记录为准。真实第三方服务和自建域名的端到端验证需要网络与配置，不能用模拟测试替代。第三方数据和 API 规则分别见 [功能清单](FEATURE-COVERAGE.md)，流向见 [隐私说明](PRIVACY.md)。

## 报告问题

优先使用本仓库 GitHub Security → Report a vulnerability（仓库启用后可见）。未提供私密入口时，公开 Issue 仅提交不含利用细节的联系请求；不要公开密钥、未脱敏报告或尚未修复的漏洞利用信息。

报告时提供版本/提交号、Node 与浏览器版本、最小复现步骤、预期与实际结果，以及脱敏后的请求信息即可。如果发现密钥已泄露，先在对应提供方撤销并重新生成；仅从 Git 最新版本删除文件不能消除已经公开的历史副本。

本项目没有声称经过独立渗透测试或安全认证。

## DNS 兼容模式

默认 `DNS_MODE=auto` 仅在所有非公网回答都属于 198.18.0.0/15 Fake-IP 地址池时改用 Cloudflare DoH。普通内网结果、混合内网结果和系统解析失败不会自动外发到 DoH。`system` 关闭此回退；`doh` 显式查询公共 DoH。DoH 固定使用 HTTPS 1.1.1.1，不依赖系统 DNS 启动、不跟随重定向；回答仍需通过公网地址校验，实际 HTTPS 连接固定到验证后的地址。工具不会更改主机代理、DNS 或证书设置。
